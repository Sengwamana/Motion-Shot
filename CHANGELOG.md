# Changelog

All notable changes to Motion Shot will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-31

### Added
- Initial release of Motion Shot
- Hand gesture control via MediaPipe Hands
- AI strategic analysis using Gemini 3 Flash
- 6 bubble colors with unique point values
- Real-time debug panel showing AI decision process
- Combo multiplier for large cluster clears
- Particle explosion effects
- Mobile/tablet blocking overlay (desktop-only experience)
- Professional documentation suite

### Technical
- React 19 with TypeScript 5.8
- Vite 6 build system
- Tailwind CSS styling
- Canvas-based game rendering
- Hybrid state management (useState + useRef)
